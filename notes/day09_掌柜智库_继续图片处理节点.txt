
1. 图片处理节点: node_md_img
   节点的作用理解:
       将md_content内容中的图片进行意图识别和切换网络地址  ![](./) -> ![描述](http)
       [描述] -> 模型识别 图片也有真正的作用了
       (http) -> 任何位置进行显示
     现在: md_path
       1. 找到所有图片和图片对应的上下文信息
       2. 交给视觉模型进行分意图识别 图片 =  语义
       3. 将图片上传到文件服务器    图片 =  网络地址
       4. 将md_content内容进行更新和替换 -> md_content
       5. md_content内容备份 -> 文件名_new.md
       6. 更新state [md_path / md_content]
     最终: md_content / md_path -> 新的内容
   节点的参数说明:
     入参:
           md_path -> images对应地址 -> md_content
     出参:
           md_path  md_content

        1.6 基于md_path_obj获取images_path_obj对象
        1.7 返回三个核心参数 ...
     2. 图片的非空内容校验,为空提前终止,进行下一个节点images_path_obj [不需要封装成函数]

     3. 查找images_path_obj每张图片对应的上下文信息(images_path_obj,md_content) -> [(图片名.name,图片的完整地址:str/Path,(上文,上文)),2,3,4]
