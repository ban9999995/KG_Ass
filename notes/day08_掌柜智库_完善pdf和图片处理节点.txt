   节点的作用理解:
      将非结构化的数据 -> minerU -> 结构化数据md
      非结构化的文件地址 -> minerU -> 本地生成结构化的md文件 -> 文件地址 -> md_path
   节点需要的参数
      入参:  task_id , pdf_path , local_dir
      出参:  md_path
   节点步骤的分析:
      1. 获取请求参数并且校验 -> 函数  pdf_path , local_dir
         validate_data_and_paths(state) -> tuple[Path,Path]
         步骤1: 获取参数 pdf_path , local_dir -> str
         步骤2: 非空校验
               pdf_path  -> 空 -> 不行 -> error
               local_dir -> 空 -> 行   -> warning
         步骤3: 将字符串转成Path
         步骤4: 存在性校验
               pdf_path -> 对应的文件 -> 没有 -> error FileNotFoundError
               local_dir -> 对应的文件夹-> 没有 -> warning 创建即可
         步骤5: 返回结果  Path
      2. minerU申请解析和文件上传以及轮询获取解析结果 -> zip_url
         upload_pdf_and_poll(pdf_path_obj:Path) -> str:
         1. 向minerU申请文件上传地址(获取上传地址/batch_id)
         2. 向指定地址发起请求上传pdf文件
         3. 使用batch_id轮询获取解析结果,提取zip_url
      3. md文件的压缩包下载,并且解压和重命名问题 -> md_path
         md地址:Path =  download_zip_and_extract_md(zip_url,local_dir_obj,local_file_path_obj.stem)
         本意: zip_url -> 下载 -> .zip -> 解压了 ->  md -> md地址
         1. 下载文件到output中,名称为 文件名.zip
         2. 检查是否存在解压的文件夹 (/output/文件名)
            有   -> 清空原有的文件夹
            没有 -> 创建新的文件夹
         3. 解压文件到文件夹中
         4. 如果文件名叫full.md重命名-> 文件名.md
         5. 返回地址即可
      4. 更新state状态 md_path并且返回state
   节点技术点总结:
      Path对象的创建: Path() 相对地址 Path(__file__)  Path(Str地址)   Path(Path)
                    iterdir() -> 没有规则直接查找子文件/文件夹  glob() 根据规则查找子文件或者子文件夹[不会递归]  rglob() [**/ 会递归]
                    new_path : with_name(新的文件名)
                    md_file_obj =   oldPath.rename(命名的新的Path  名称 -> 运行文件夹 || 全名称  new_path)
      MinerU使用流程: 1. 申请文件上传地址 2. 向指定地址进行文件上传 3. 轮询获取解析结果
      requests的使用:    requests. get post put delete -> request(method="post")
                                   1.要请求体 post put 2. 动作行为  更新头像 -> put
                                   2.传递参数方式 path params -> 唯一标识 path 筛选参数 params  json+字节形式  -> put post  1.无法路径条件json 字节 2. 隐私数据  3. 超过2kb的字符串
                                   3. requests.post(url,headers=,params=,json=,data=,timeout)
                                   4. 结果解析  response . status_code / json() / content / text
                                   5. requests.Session()  session.trust_env = False   session = requests
      shutil的使用:  .rmtree(文件夹) 删除文件夹   .unpack_archive(要解压的压缩文件,解压的地址)  make_archive(文件名 xx ,压缩格式 zip , 压缩的文件或者文件夹)
