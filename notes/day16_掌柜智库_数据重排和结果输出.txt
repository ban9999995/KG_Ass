          批量打分
          scores:list[float] = reranker.compute_score([['问题', '答案'], ['what is panda?', 'The giant panda (Ailuropoda melanoleuca), sometimes called a panda bear or simply panda, is a bear species endemic to China.']])

          bge-reranker-large -> 512 token -> 一对 问题+答案 (批量也是一对问题+答案,不是所有的列表)

          正视问题: 超过了怎么办?
            1. 冷处理  不处理  超过了处理截取! 1000 -> 512 -> 打分
            2. 换模型  换大的模型
            3. 压缩处理  超过了使用大语言模型进行内容压缩 注意:压缩的结果只能用于打分,不能用于后期给模型做参考答案!
          进行content压缩处理: 算token数量!!!
            (问题 + 答案 -> token ) 算token  -> 大于512 -> 模型 -> (压缩) -> 字符
              100   600
            模型本身的自带的分词器 tokenizer =  reranker.tokenizer  ->   token_id_list:[1,3,5,6,10,29] =  tokenizer.encode(字符串)
                                                                    -> len(token_id_list) = token的数量
          注意事项:  bge-reranker-large -> max_position_embeddings -> 514 -> 起始和结束符号 2 -> 512 -> 问题和答案分割符号 4 -> 508
                    <起始分割>问题</结束分割><起始分割>答案</结束分割>
       5. 修改模型的infra
            # 4. reranker模型  打分 = 算token数量
            def compute_scores(self,question_answer_pair:list[list[str]]) -> list[float]:
                reranker_model = get_reranker_model()
                score_list: list[float] = reranker_model.compute_score(question_answer_pair)
                return score_list
            def compute_token_number(self,data:str)->int:
                reranker_model = get_reranker_model()
                tokenizer = reranker_model.tokenizer
                # encode() 获取字符串转成token的id的列表!
                # add_special_tokens -> 计算token的时候,不要考虑特殊字符(分割字符)  514 - 2 -4 = 508
                token_id_list =  tokenizer.encode(data,add_special_tokens=False)
                token_number:int = len(token_id_list)
                return token_number
